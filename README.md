## Repository layout

Each experiment has its own folder:

```
Experiment NN/
├── Experiment N.md   ← theory, commands and procedure (Experiments 01–08)
├── ExperimentN.pdf   ← output
└── PDF.md            ← download link for the PDF
```

> All experiments are meant to be run only on your own machines or in an authorised lab network.
